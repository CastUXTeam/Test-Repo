# CAST Landing Page

A professional landing page for CAST Application Intelligence Platform featuring left navigation and comprehensive platform information.

## Features

- **Left Navigation Menu**: Fixed sidebar navigation with smooth transitions between sections
- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Platform Overview**: Detailed information about CAST's capabilities and features
- **Knowledge Graph Visualization**: Interactive SVG diagram explaining the CAST Knowledge Graph
- **Key Insights**: Statistical highlights showcasing platform effectiveness
- **Modern UI/UX**: Clean, professional design with gradient colors and smooth animations

## Sections

1. **Home**: Welcome section with platform overview, feature cards, graph explanation, and insights
2. **Platform**: Overview of the CAST Application Intelligence Platform
3. **Knowledge Graph**: Information about software architecture relationships
4. **Insights**: Analytics and insights information
5. **About**: Company and technology information

## Files

- `index.html` - Main HTML structure
- `styles.css` - Complete styling and responsive design
- `script.js` - Navigation functionality

## How to Use

### Local Development

Simply open `index.html` in a web browser, or use a local server:

```bash
# Using Python 3
python3 -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js
npx http-server
```

Then navigate to `http://localhost:8000` in your browser.

### Navigation

Click on any menu item in the left sidebar to navigate between sections. The active section is highlighted in the navigation menu.
